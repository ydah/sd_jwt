SD-JWT / Compact · JWS JSON

Share selected claims with verifiable presentations

Issue, selectively present, and verify RFC 9901 SD-JWTs in Ruby. Use ruby-jwt and OpenSSL for signatures, with recursive disclosures and holder key binding handled by the gem.

Get started Read the documentation

Ruby 3.3+MIT licenseRubyGems

  • Issue disclosures

    Create credentials with selectively disclosed object claims, array entries, and nested values.

  • Choose what to share

    Select disclosure paths and bind a presentation to a holder key, audience, and transaction nonce.

  • Set verification policy

    Verify Compact and JWS JSON forms with explicit algorithms, issuer trust, required claims, and limits.

Installation

Add the gem to your Gemfile:

gem "sd_jwt"

Run bundle install, then try the quick start. Requires Ruby 3.3 or later.

For supported dependencies and optional integrations, see the installation guide.

Scope & documentation

Applications must establish issuer trust and manage nonce replay protection, revocation, and credential profile rules. Parsing alone does not authenticate a credential. EdDSA, symmetric holder keys, and SD-CWT are outside scope.

Read the full documentation for supported formats, examples, and API details.

No independent external human security audit has been completed. Automated tests and RFC conformance checks do not replace such an audit. Security policy.
